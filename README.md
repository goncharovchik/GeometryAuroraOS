# Geometry Dash (Aurora OS Edition)

2D ритм-платформер на базе фреймворка Flutter для мобильной операционной системы ОС Аврора 5. Проект использует нативный C++ Embedder (Wayland/EGL) без применения QML.

## Требования

- Windows 10/11 x64
- Docker Desktop (образ `aurora-build-tools:5.2.1.200`)
- Flutter SDK (3.8.x+)
- Эмулятор ОС Аврора 5.2.1 (VirtualBox) с настроенным каталогом `vmshare`
- Для первичной проверки и автоматической настройки окружения предназначен `setup_environment.bat` (или `setup_environment.ps1`).

## Сборка и запуск

- `build_and_run_aurora.ps1` — компиляция Flutter-бандла, сборка RPM в Docker, установка и запуск в эмуляторе.
- `build_flutter_rpm.ps1` — компиляция RPM-пакета без развертывания (`ru.aurora.geometry_dash_aurora-1.0.0-1.x86_64.rpm`).
- `run_aurora.ps1` — запуск установленной игры в запущенном эмуляторе.
- `start_emulator.bat` (`start_emulator.ps1`) — запуск виртуальной машины эмулятора Авроры.

## Структура проекта

- `lib/` — исходный код игры (Dart): детерминированная физика, рендеринг, игровой цикл, уровни и экраны.
- `aurora/` — платформа ОС Аврора: точка входа C++ embedder, CMakeLists.txt, spec-файл RPM, desktop-файл и иконки.
- `icons/` — иконки приложения различных разрешений.
- `test/` — тесты физической модели и логики игры.

## Управление

- **Прыжок / действие:** Пробел (Space), Стрелка вверх, клик мыши или касание сенсорного экрана.
- **Пауза:** Клавиша Escape или кнопка интерфейса.
